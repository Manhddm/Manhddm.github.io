## 🛠️ Phát triển tại máy cục bộ (Local Development)

Cài đặt các thư viện phụ thuộc:

```bash
npm install
```

Chạy server phát triển (tự động mở trình duyệt và hot-reload):

```bash
npm start
```

Đóng gói bản build tĩnh (kiểm tra lỗi liên kết và tìm kiếm nội bộ):

```bash
npm run build
npm run serve
```
